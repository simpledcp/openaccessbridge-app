  1. 1. Select the input device

    Detected capture inputs, by their stable identifier (§6.1) — never a card index.

    Input hardware tier

    What is physically feeding this input (§6.2). The tier decides how harshly the signal is judged: a built-in mic jack is warned about far earlier than a line-input USB interface.

  2. 2. Select the intended use

    Which accessibility feed(s) this input serves. HI and VI-N stay independent.

  3. 3. Select the channel mapping

    Which captured channel feeds which named stream (§6.5). A mapping this device cannot satisfy is not offered here at all — that fault belongs before a show, not during one.

  4. 4. Play a known signal

    From the cinema system, play something into this input and leave it playing: a test tone, trailer audio, or the venue's accessibility feed. Then start the meter below.

    If the room is silent the wizard will report "no signal" — which is a real fault during calibration, not a quiet passage.
